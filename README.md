Irrigua
Protótipo de um site/app para controlar a rega das plantas — estética verde musgo/oliva com rosa, tipografia Cormorant Garamond + DM Sans.
Conteúdo
`design/Main.dc.html` — tela "Meu jardim" (painel do dia, semana, cards das plantas, visão semanal)
`design/Logo.dc.html` — logo, rodada 1 (A: regador, B: broto na gota, C: monograma I)
`design/canvas.json` — disposição dos quadros no canvas
`fotos/` — fotos de exemplo usadas no protótipo
Os arquivos `.dc.html` são do editor de design do Claude e abrem completos no próprio artefato. As fotos de exemplo vêm do projeto aberto deilen (dataset do Kaggle / Unsplash) e servem só para o protótipo.
