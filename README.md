# Irrigua

Protótipo de um site/app para controlar a rega das plantas. Paleta oliva escuro com rosa e sálvia, tipografia Fraunces (títulos) + Plus Jakarta Sans (interface). Símbolo: a gota que é folha.

## Páginas

- `index.html` — tela "Meu jardim": painel do dia, semana, cards das plantas com ficha de informações (botão "i") e visão semanal. Clicar em "Reguei" registra a rega no próprio navegador.
- `logo.html` — a marca (rodada 2 do símbolo; escolhido: D, a gota que é folha).
- `icone.svg` — ícone da aba do navegador.

## Pastas

- `fotos/` — fotos de exemplo usadas no protótipo.
- `design/` — arquivos das telas no editor de design do Claude (`.dc.html` + `canvas.json`). Abrem completos no próprio artefato; o site não depende deles.

As fotos de exemplo vêm do projeto aberto [deilen](https://github.com/antonia-white/deilen) (dataset do Kaggle / Unsplash) e servem só para o protótipo.
