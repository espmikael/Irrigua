# Irrigua

Protótipo de um site/app para controlar a rega das plantas — estética verde musgo/oliva com rosa, tipografia Cormorant Garamond + DM Sans.

## Conteúdo

- `design/Main.dc.html` — tela "Meu jardim" (painel do dia, semana, cards das plantas, visão semanal)
- `design/Logo.dc.html` — logo, rodada 1 (A: regador, B: broto na gota, C: monograma I)
- `design/canvas.json` — disposição dos quadros no canvas
- `fotos/` — fotos de exemplo usadas no protótipo

Os arquivos `.dc.html` são do editor de design do Claude e abrem completos no próprio artefato. As fotos de exemplo vêm do projeto aberto [deilen](https://github.com/antonia-white/deilen) (dataset do Kaggle / Unsplash) e servem só para o protótipo.

## Ver online (GitHub Pages)

- `index.html` — a tela "Meu jardim", em HTML comum, funcionando: clicar em "Reguei" registra a rega no próprio navegador.
- `logo.html` — as três propostas de logo.
- `icone.svg` — ícone da aba do navegador.

Para publicar: no repositório, vá em **Settings › Pages**, em *Source* escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)` e salve. Em um ou dois minutos o site fica em `https://SEU-USUARIO.github.io/irrigua/`.
